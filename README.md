# ระบบออกใบส่งซ่อมรถยนต์เช่า (Authorized Service Center)

ระบบออกเอกสาร **ใบส่งซ่อมรถยนต์เช่า** มาตรฐานกองรถยนต์หลวง (กระดาษ **F4: 8.5 × 13 นิ้ว**) พร้อมระบบแนบรูปภาพหน้า 2+, ฐานข้อมูลประวัติการส่งซ่อมแบบออฟไลน์ (**SQLite**), ส่งออกไฟล์ **Microsoft Word (`.docx`)** ต้นฉบับ 100% และ **Excel (`.csv`)**

## ฟีเจอร์หลัก
- แบบฟอร์มหน้า 1 จัดวางตารางและเส้นประตรงตามต้นฉบับหน่วยงาน (ขนาด F4)
- รองรับการเลือกทะเบียนรถ (`ส.น.ว. 1816` – `1820`) พร้อมเลือกชื่อเจ้าหน้าที่ขับรถประจำคันให้อัตโนมัติ (รวมถึงระบบสลับเวรวันที่ 1–15 / 16–31 สำหรับ `ส.น.ว. 1816`)
- แนบรูปภาพหน้า 2+ ได้ไม่จำกัด (จัดกริด 2 คอลัมน์อัตโนมัติ 6 รูปต่อหน้า F4)
- ส่งออกและเปิดใน Microsoft Word (`.docx`) จากไฟล์แม่แบบ `master_template.docx`
- ฐานข้อมูลประวัติการส่งซ่อม SQLite (`car_service.db`) พร้อมหน้าต่างค้นหา อัปเดตสถานะ และส่งออก Excel (`.csv`)
- รองรับหน้าจอความละเอียดสูง (ปรับขนาดเมนูและซูมกระดาษพรีวิวได้อิสระโดยไม่กระทบขนาดตอนสั่งพิมพ์)

## วิธีใช้งาน (โหมดพัฒนา)
1. ต้องมี Python 3.10+ และติดตั้ง `Pillow`:
   ```bash
   pip install pillow
   ```
2. ดับเบิลคลิก `Start_App.bat` หรือรัน:
   ```bash
   python server.py
   ```
3. เปิดเบราว์เซอร์ไปที่ `http://localhost:8085`

## วิธีสร้างไฟล์ `.exe` (Standalone สำหรับเครื่องออฟไลน์)
1. ติดตั้ง PyInstaller:
   ```bash
   pip install pyinstaller
   ```
2. ดับเบิลคลิก `Build_EXE.bat`
3. นำไฟล์ `dist/CarService_RepairOrder.exe` ไปใช้งานบนเครื่องอื่นได้ทันทีโดยไม่ต้องลง Python
